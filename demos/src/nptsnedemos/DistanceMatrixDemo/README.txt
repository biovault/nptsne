Purpose
=======
Demonstrate initializing the TextureTsneExtended API with a self calculated distance matrix

Install 
=======

Unpack data (if needed)

> python ../unpack_data

Install nptsne

> pip install nptsne

Run
===
> python test_dist.py

Result
======
Will produce a tSNE embedding 10000 data point subset of the MNIST digits.
